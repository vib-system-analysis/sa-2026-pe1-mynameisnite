# Отбор резюме под вакансию

**Код темы:** `БЗ12`

**Область:** свободный текст, документы, найм, исследование пользователей

Система помогает рекрутеру отбирать кандидатов: анализирует резюме относительно описания вакансии, сопоставляет навыки, опыт и требования, рассчитывает оценку соответствия и ранжирует кандидатов. Для наиболее подходящих кандидатов система формирует персональные вопросы для интервью, опираясь на их опыт и пробелы в навыках. Предусмотрена интеграция с популярными HR-системами.

## Зачем нужен проект

Автоматизировать первичную оценку кандидатов, ускорить процесс отбора и повысить качество найма.

## Что предстоит выяснить

- Какие требования вакансии действительно необходимы, а какие перенесены из шаблона.
- Как оценивать релевантный опыт, если названия должностей различаются.
- Как убедиться, что система не воспроизводит предвзятость.
- Как составлять письмо об отказе и кто должен его подписывать.

## Контекст и границы системы

Основной процесс — рекрутер разбирает множество резюме для одной вакансии. Система обрабатывает резюме в свободной форме и в файлах, сопоставляет их с текстом требований и помогает принять решение о дальнейшем движении кандидата по этапам найма.

Результат затрагивает реального человека: кандидат может получить отказ. Поэтому система должна поддерживать осмысленное решение рекрутера, а не превращать оценку модели в непрозрачный автоматический отсев. Отдельное ограничение — исключить влияние признаков, не относящихся к работе.

## Проверка качества и безопасности

- Рекрутер должен быть согласен с результатами отбора.
- При равном опыте решения не должны различаться из-за пола, возраста или вуза.
- Для проверки предвзятости используются пары резюме, отличающиеся одним признаком.
- Резюме для тестирования берутся синтетические либо предоставляются однокурсниками с их согласия.
- Нужно учитывать атаки через инструкции, спрятанные в резюме, например текст белым цветом с требованием выбрать кандидата.
