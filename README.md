AI.English — бесплатный онлайн-ассистент для изучения английского с разными уровнями и персонажами. 

Платформы: Web-версия и тонкая настольная клиент-версия для компьютера.
Авторизация: Google, Apple, Email. 
Монетизация: реклама, подписки и внутриигровые покупки.

3 режима работы:
1. Свободная беседа — общение на любые темы.
2. Сценарный диалог — отработка конкретных ситуаций.
3. «Найди ошибки» — ИИ специально допускает неточности, которые нужно исправить.

Система: сохранение прогресса, уровни и оценки. Встроенный справочник по грамматике и лексике.
