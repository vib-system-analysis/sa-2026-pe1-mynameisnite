# AI.English

AI.English — проектируемый помощник для разговорной практики английского. Он должен объединить свободный и сценарный диалог, включая рабочие ситуации, понятный разбор ошибок и историю занятий. Это будущий продукт (TO-BE); текущий процесс обучения без него описан отдельно ниже.

## Краткое описание проекта

Сейчас учащийся собирает практику из разных источников: приложений, видео, словарей, переводчиков, чат-ботов и занятий с преподавателем. AI.English должен сократить переключения между ними: пользователь сможет репетировать разговоры, получать обратную связь по ошибкам и возвращаться к истории занятий. Задача MVP — проверить, помогают ли эти функции заниматься регулярнее и увереннее говорить по-английски.

## Текущая система (AS-IS)

Когда возникает учебная или рабочая задача, человек ищет правило или пример, составляет фразу, проверяет её по словарю, переводчику или у собеседника и затем использует результат. Если обратную связь не удаётся быстро получить, он может отложить задачу или выбрать первое найденное решение. Это описание процесса для проверки; частота и причины таких задержек пока не измерены.

## Основные функции

- Свободная беседа на любые темы.
- Сценарный режим для типичных жизненных и рабочих ситуаций.
- Режим «Найди ошибки» для отработки грамматики и лексики.
- Авторизация через Google, Apple или Email.
- Сохранение прогресса, уровней и оценок.
- Встроенный справочник по грамматике и словарю.

## Цель MVP и критерии проверки
**Целевая гипотеза MVP:** доля пользователей, не вернувшихся в течение 7 дней после регистрации, не превышает 35%; медианное время от запуска до первого содержательного диалога — не более 2 минут. Текущий baseline неизвестен: данные отсутствуют, сбор когортных событий в PostHog не настроен. Порог 35% — цель пилота, а не текущий результат.

## Границы AI.English (TO-BE)

Входит в систему:
- пользовательский интерфейс web и desktop;
- диалог с ИИ;
- сценарные задания;
- проверка ошибок и рекомендации;
- учёт прогресса и статистики;
- процессы авторизации и подписок.

Не входит в систему:
- офлайн-обучение в классах;
- проведение официальных экзаменов;
- создание учебных материалов вручную для каждого пользователя;
- прямое управление учебным процессом преподавателя вне платформы.

## Заинтересованные стороны

| Сторона | Цель и ориентир успеха |
| --- | --- |
| Пользователи | Начать содержательный диалог не более чем за 2 минуты и практиковаться без отвлекающей рекламы; это целевой ориентир MVP, его нужно проверить в пилоте. |
| Преподаватели и методисты | Сократить время на проверку типовых ошибок примерно на 70%, сохраняя ручную проверку сложных случаев; гипотеза до замеров. |
| Разработчики | Обеспечить не менее 99,5% сессий без аварийного завершения локального приложения; проверять по локальным crash-логам. |
| Владельцы продукта | Проверить экономическую устойчивость: предварительная гипотеза LTV > 3000 ₽ при CAC < 800 ₽. Реальных платежных данных пока нет. |
| Работодатели и учебные заведения | Получить сотрудника или учащегося, способного решать рабочие и учебные задачи на английском; критерии результата нужно согласовать с организацией. |

**Конфликт интересов:** владельцам может быть выгодна реклама, а пользователям нужна непрерывная практика. Гипотеза для теста: баннер после каждого пятого сообщения может уменьшить повторные сессии примерно на 15%; этот эффект не измерен. Возможный компромисс — показывать рекламу только вне диалога.

## Критерии успеха


Все значения ниже — цели пилота, а не подтверждённые результаты. Сбор аналитики сейчас не настроен.

- **Отток D7:** ≤ 35%; данные отсутствуют, требуется настройка когортного сбора в PostHog или локального журнала сессий.
- **DAU/MAU:** ≥ 25%; рассчитывать по уникальным активным пользователям в SQLite или self-hosted PostHog с согласием.
- **Повторные занятия:** медианный интервал между сессиями ≤ 48 часов; источник — временные метки сессий в SQLite.
- **Оценка занятий:** ≥ 70% оценённых сессий получают от пользователя не менее 4 из 5; источник — локальная форма оценки после занятия.
- **Обучающий результат:** ошибки на 50 реплик снижаются на 30% у участников, занимающихся не реже 3 раз в неделю; проверять входным и итоговым заданиями по одной рубрике.
- **Надёжность локального MVP:** ≥ 99,5% сессий без аварийного завершения; источник — локальные crash-логи. Доступность API ≥ 99,5% применима только если появится серверный API; тогда проверять Prometheus/Grafana.
- **Конверсия trial→paid:** целевой ориентир ≥ 12% среди пользователей с медианным интервалом между сессиями ≤ 24 часов; данные отсутствуют до запуска триала и оплаты, затем источник — отчёт платёжного провайдера.
- **Экономика:** LTV > 3000 ₽ и CAC < 800 ₽ — предварительная гипотеза; данных о платежах и привлечении нет, расчёт возможен после запуска продаж и фиксации расходов.

Для соблюдения локального хранения аналитика не должна отправлять аудио, тексты диалогов или персональные данные без отдельного согласия. До выбора аналитики можно хранить минимальные агрегированные события локально. Amplitude, PostHog, Prometheus, Grafana и платёжный провайдер не считаются подключёнными источниками данных.

## Платформы и монетизация

- Веб-версия и легковесный десктопный клиент.
- Возможные модели монетизации: подписка или реклама вне активного диалога. Модель и спрос не подтверждены платежной аналитикой; реклама внутри разговора может конфликтовать с непрерывной практикой.

## Роль проекта в образовательной среде

AI.English решает задачу цифровой персонализации обучения: пользователь получает постоянный доступ к языковой практике без необходимости постоянного участия преподавателя. Это снижает барьеры входа, повышает доступность и делает процесс обучения более адаптивным.
